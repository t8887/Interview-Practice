# 22-Revision

Spaced-repetition queue, populated and cleared by `/prep-revise`. Not a content folder — it tracks *when* to re-look at content that already exists elsewhere in the repo.

## Rules (mechanical, no willpower needed — per `_meta/WEEKLY_PLANS.md`)

- Every solved problem / finished note gets `next_review: +1d`.
- Clean recall → +3d → +7d → +21d → *mastered*.
- Any failure → back to +1d.
- Friday clears the whole due queue before new material starts.

## `queue.md`

Created on first use by `/prep-revise`. One line per item: `topic | file path | next_review date | current streak`.

**Constraint from your own history:** if maintaining this queue takes more than 10 minutes a day, simplify it — don't perfect it. The previous 30-day sprint (`TRACKING.md`) died partly from tracking overhead.
