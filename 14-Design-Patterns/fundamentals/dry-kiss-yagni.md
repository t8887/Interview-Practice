DRY / KISS / YAGNI — Pragmatic fundamentals

Definitions
- DRY: Don’t Repeat Yourself — avoid duplication.
- KISS: Keep It Simple, Stupid — prefer simpler solutions.
- YAGNI: You Ain't Gonna Need It — don’t build what’s not needed now.

Trade-offs table
| Principle | Benefit | Risk if over-applied |
|---|---|---|
| DRY | Easier maintenance | Premature abstraction that hides intent |
| KISS | Faster delivery, easier reasoning | Under-engineering complex requirements |
| YAGNI | Less wasted work | Rework if future needs force redesign |

Interview tip
- Explain pragmatic application: start simple, extract abstraction when duplication or complexity justifies it.
